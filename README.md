# Сборник игр dvoeplay

Десять игр для двоих на одном телефоне, против ИИ или по сети: «4 в ряд», «Магнитный бой», «Мемо-дуэль», «Матрёшка», «Точки и квадраты», «5 букв», «Быстрая виселица», «Захлопни ящик», «Доббль» и «Взломщик кода».

[Открыть сборник](https://dvoeplay.netlify.app/). Есть общие имена, настройки, история и статистика пары, мини-турнир с фантами и PWA с офлайн-режимом. Самостоятельные игры студии не входят в этот продукт.

## Запуск и проверки

В корне репозитория:

```sh
npm ci
npx playwright install chromium
npm run dev
```

Открыть `http://localhost:8787/`. Локальные комнаты хранятся в памяти и исчезают при перезапуске сервера.

```sh
npm test         # комнаты, гонки записи, границы раундов, свойства игр
npm run audit    # синтаксис и согласованность 15 файлов
```

При запущенном локальном сервере:

```sh
TEST_BASE_URL=http://localhost:8787/ npm run test:browser
```

Полный прогон содержит **27 наборов проверок**: десять игр, сеть, имена и темы, каталог, статистика, турниры, клавиатура, раскладка, офлайн, потеря связи, длинные партии, доступность диалогов и анимации. Логи и JSON сохраняются в `docs/testing/latest/`. `TEST_REPORT_DIR` меняет папку результатов; `TEST_FILTER` выбирает тесты через запятую.

[Результаты проверки и измерения анимаций от 7 октября](docs/motion/2026-10-07/REPORT.md). Оснастка работает с установленными локально Playwright и Chromium. Оригинальные выгрузки Claude и история восстановления хранятся отдельно в локальной рабочей папке.

## Структура

| Путь | Назначение |
| --- | --- |
| `public/index.html` | Каталог, настройки, статистика, создание турнира |
| `public/*.html` | Десять игр |
| `public/net.js` | Общая сеть и лобби |
| `public/tour.js` | Мини-турнир |
| `public/motion.css`, `public/motion.js` | Движение диалогов, видимость и пауза заставок |
| `public/sw.js` | Офлайн-кеш `dvoeplay-v10` |
| `assets/dobble/` | Исходные иллюстрации OpenMoji, лицензия и измеренные границы рисунков |
| `netlify/functions/room.mjs` | Серверная функция `/api/*`, условная запись Netlify Blobs |
| `netlify/functions/lib/rooms.mjs` | Логика комнат, очередь, результаты и реванши |
| `tools/` | Локальный сервер, аудит, тесты и измерение анимаций |

[Оформление и правила анимаций](DESIGN.md). [Обновление «Доббля»: два диска и цветные предметы](docs/dobble/2026-10-08/REPORT.md).

Иллюстрации «Доббля» встроены в HTML и работают офлайн. Их можно заново собрать из сохранённых SVG командой `node tools/build-dobble-art.mjs`; происхождение, лицензия и адаптация описаны в `assets/dobble/README.md`.

## Публикация

Netlify связан с [shottk8-art/dvoeplay](https://github.com/shottk8-art/dvoeplay), веткой `main`. Публикуется **`public/`**, серверные функции — **`netlify/functions/`**, настройки — **`netlify.toml`**. Сборка интерфейса не нужна; Netlify устанавливает зависимости из lockfile. Изменение основной ветки запускает публикацию.

Для проверки временной или основной публикации:

```sh
DEPLOY_BASE_URL=https://your-deploy.netlify.app/ node tools/test-deployment.mjs
```

Эта проверка создаёт собственную временную комнату на указанном сайте, проверяет конкурирующие чтения и записи, результаты и реванши, затем закрывает комнату. Не запускается автоматически в локальном полном прогоне.

Старые корневые дубли в репозитории — история. Рабочие файлы находятся в `public/`, инструменты — в `tools/`. Не публиковать корень общей рабочей папки или соседний студийный проект.
